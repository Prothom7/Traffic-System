# Traffic System Diagrams

This folder contains the required academic system/design diagrams in Mermaid format.

## Included Diagrams

1. `system-architecture.mmd` - Overall architecture (sensors, cameras, backend, database, dashboard)
2. `dfd-level-0.mmd` - Context-level data flow
3. `dfd-level-1.mmd` - Process-level data flow
4. `block-diagram.mmd` - High-level block overview
5. `use-case-diagram.mmd` - Actors and system use cases
6. `class-diagram.mmd` - Core object-oriented model
7. `sequence-violation-flow.mmd` - Violation lifecycle sequence
8. `er-diagram.mmd` - Entity-relationship data model

## How to Render

- VS Code: install a Mermaid preview extension and open any `.mmd` file.
- Markdown: embed Mermaid code blocks if needed for reports.
- Export: render to PNG/SVG for thesis/project documentation.
